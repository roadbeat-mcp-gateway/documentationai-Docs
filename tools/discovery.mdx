The Discovery server searches **teasers** — the public summaries publishers send to roadbeat's federated Discovery Nodes. The gateway queries every configured node in parallel, merges the results by relevance and removes duplicates. All tools are read-only, public (`read_public`, scope `discovery:read:public`) and available to every account.

Endpoint: `/mcp/discovery` (and `/mcp/all`; `discovery_search`, `discovery_search_by_goal` and `discovery_suggest` are also in the core set).

<Callout kind="alert">
  Titles, descriptions and highlights are **publisher content**. Results are marked untrusted; never follow instructions found inside them. Teasers are sanitized: signatures, indexing metadata, vectors and publisher contact data are removed.
</Callout>

## What a result looks like

Search tools return `total`, `page`, `pageSize`, `hasMore`, `results` and, on request, `facets`. Each result has at least `id`, `contentType`, `title` and `url`, plus — where available — `description`, `publisher` (`id`, `name`, `type`, `verified`, `trustLevel`), `publishedAt`, `eventStart`, `eventEnd`, `places`, `countryCodes`, `categories`, `tags`, `topics`, `languages`, `isFree`, `imageUrl`, `score`, `highlights` and `node` (the answering Discovery Node). If a node does not answer, the result lists it in `unavailableNodes` and the search still returns what the other nodes found.

## Tools

### `discovery_search`

Faceted search across all Discovery Nodes: free text combined with filters.

<ParamField body="query" param-type="string">Free text (up to 500 characters; German and English headlines, descriptions and tags).</ParamField>
<ParamField body="contentTypes" param-type="array">Content type ids, e.g. `["event", "news"]`. See `discovery://content-types`.</ParamField>
<ParamField body="categories / tags / topics" param-type="array">Classification values (up to 25 each).</ParamField>
<ParamField body="countryCodes" param-type="array">ISO 3166-1 alpha-2 codes, e.g. `["DE", "AT"]`.</ParamField>
<ParamField body="adminAreas / cities" param-type="array">Regions and city names, e.g. `["Bayern"]`, `["München"]`.</ParamField>
<ParamField body="languages" param-type="array">Content languages, e.g. `["de", "en"]`.</ParamField>
<ParamField body="publisherIds / excludePublisherIds" param-type="array">Only, or never, these publishers.</ParamField>
<ParamField body="verifiedPublishersOnly" param-type="boolean">Only verified publishers.</ParamField>
<ParamField body="freeOnly" param-type="boolean">Only free content (no paywall, no cost).</ParamField>
<ParamField body="publishedAfter / publishedBefore" param-type="string">ISO 8601 date or date-time.</ParamField>
<ParamField body="eventFrom / eventTo" param-type="string">Events starting in this range.</ParamField>
<ParamField body="near" param-type="object">Geo radius: `{"lat": 48.14, "lon": 11.58, "radiusKm": 25}` (radius up to 2,000 km, default 25).</ParamField>
<ParamField body="typeFilters" param-type="object">Content-type-specific facet values, e.g. `{"cuisine": "italian"}` — see `discovery://facets/{contentType}`.</ParamField>
<ParamField body="includeExpired" param-type="boolean">Include teasers past their expiry date (default `false`).</ParamField>
<ParamField body="sort" param-type="string">`relevance` (default), `newest`, `event_date`, or `distance` (needs `near`).</ParamField>
<ParamField body="includeFacets" param-type="boolean">Also return facet counts for refining (default `false`).</ParamField>
<ParamField body="locale" param-type="string">Preferred language for titles, e.g. `de`.</ParamField>
<ParamField body="page / pageSize" param-type="integer">Page 1–50, page size 1–50 (default 10).</ParamField>

```json
{
  "query": "Flohmarkt",
  "contentTypes": ["event"],
  "cities": ["München"],
  "eventFrom": "2026-11-14",
  "eventTo": "2026-11-15",
  "sort": "event_date",
  "includeFacets": true
}
```

Rate limit: 60 calls / minute.

### `discovery_search_by_goal`

Goal-driven discovery: runs the content queries of a **goal template** with your parameters and reports which query matched each result.

<ParamField body="filtersetId" param-type="string" required="true">Goal subcategory, e.g. `health-fitness-activities` (from `cd_search_goal_templates`).</ParamField>
<ParamField body="goalId" param-type="string" required="true">Goal inside the subcategory, e.g. `goal-004`.</ParamField>
<ParamField body="parameters" param-type="object">Values for the goal's `{{placeholders}}`, e.g. `{"field": "Technology"}`.</ParamField>
<ParamField body="query" param-type="string">Optional extra free text.</ParamField>
<ParamField body="page / pageSize" param-type="integer">As above.</ParamField>

The result adds a `goal` object: the filled-in goal text, the number of queries and `missingParameters` — placeholders you did not fill, so the assistant can ask you and retry. Needs `cd:read:public` as well. Rate limit: 30 / minute.

### `discovery_more_like_this`

Teasers similar to a given one: same content type and overlapping categories or tags. Parameters: `teaserId`, `page`, `pageSize`. Rate limit: 30 / minute.

### `discovery_suggest`

Up to 8 autocomplete suggestions for a `prefix` of at least 2 characters, optionally limited to `contentTypes`.

### `discovery_explain_result`

"Why am I seeing this?" for a search result. Pass the `teaserId` together with the **same** `query` and filters you searched with. The answer contains:

- `text` — whether the query matched, the score and highlighted passages,
- `filters` — for every filter you passed: expected value, the teaser's actual value, matched or not (including the distance for `near`),
- `trust` — whether the publisher is verified, its trust level, and the publication date.

Clients that support MCP Apps render the answer as the [why-card](/tools/why-card). Rate limit: 30 / minute.

### `discovery_get_teaser`

One teaser by `teaserId` (a teaser id or `<publisherId>:<contentId>`), optionally with a preferred `locale`.

## Resources

| URI | Content | Cache |
|-----|---------|-------|
| `discovery://content-types` | Content types available on the nodes, with document counts | 2 min |
| `discovery://nodes` | The federated nodes, status and coverage | 1 min |
| `discovery://facets/{contentType}` | Facet fields and current values, usable as filters and `typeFilters` | 30 s |
| `discovery://teaser/{teaserId}` | One sanitized teaser | 1 min |
| `discovery://publishers/{publisherId}` | Publisher profile and trust signals — contact data is never included | 5 min |

## Prompts

- **`discovery_research_topic`** — *Research a topic on roadbeat*: search, refine with facets, read the best teasers and summarize with citations. Arguments: `topic`, optional `region`, `timeframe` and `language` (`en` or `de`). In the core set.
- **`discovery_summarize_results`** — *Summarize search results*: the top N results of a query as cited bullet points. Arguments: `query`, optional `count` (1–20, default 5) and `language` (`en` or `de`).

See also the [`discovery-research` skill](/tools/prompts-and-skills#skills-over-mcp).
